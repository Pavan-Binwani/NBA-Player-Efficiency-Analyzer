# NBA-Player-Efficiency-Analyzer
In this project I am merging my interests of the NBA, data, programming, and statistics together to answer the research question of whether the NBA's highest scoring players are also the most efficient scorers. This project is going to primarily utilize true shooting percentage to help answer this question. 
All data comes from basketball reference. You can see the data yourself at: https://www.basketball-reference.com/leagues/NBA_2026_per_game.html
